# Финальный проект 6-го спринта: UI-автотесты для Яндекс.Самоката

## 📋 Описание

Автотесты для сервиса «Яндекс.Самокат» (https://qa-scooter.praktikum-services.ru/)

## 🎯 Тестовые сценарии

### 1. Раздел "Вопросы о важном" (FAQ)
- Проверка открытия ответов на все 8 вопросов
- Сверка текста ответа с ожидаемым
- Параметризация: 8 независимых тестов

### 2. Оформление заказа самоката
- Полный позитивный сценарий с двумя наборами данных
- Проверка двух точек входа: верхняя и нижняя кнопки "Заказать"
- Заполнение формы с выбором станции метро из выпадающего списка
- Работа с календарём и выпадающим списком срока аренды
- Проверка появления модального окна "Заказ оформлен"

### 3. Логотипы в шапке
- Клик по логотипу Самоката → возврат на главную страницу
- Клик по логотипу Яндекса → открытие Дзена в новом окне
